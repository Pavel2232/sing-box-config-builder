# Governance

Sing-box Config Builder is maintained by
[@Pavel2232](https://github.com/Pavel2232).

## Decision making

- Small fixes and documentation improvements are decided through pull request
  review.
- New protocols, routing defaults, and security-sensitive behavior should be
  discussed in an issue before implementation.
- The maintainer has final responsibility for releases, security disclosures,
  repository settings, and accepting or declining changes.
- Decisions prioritize user safety, compatibility with the targeted sing-box
  version, maintainability, and clear failure behavior.

Substantial decisions should be documented in the related issue or pull
request so future contributors can understand the reasoning.

## Roles

Regular contributors may be invited to review or maintain areas where they
have demonstrated sustained, constructive work. Access can be removed for
inactivity, security reasons, or Code of Conduct violations.

If the project becomes inactive, the MIT License allows the community to fork
and continue development.

## По-русски

Небольшие изменения принимаются через review. Новые протоколы, маршрутизацию и
security-sensitive изменения сначала обсуждаем в issue. Финальные решения по
релизам и безопасности остаются за мейнтейнером, а причины крупных решений
фиксируются публично в issue или PR.

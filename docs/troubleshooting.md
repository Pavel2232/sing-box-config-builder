# Устранение неполадок

## Страница не открывается

```bash
docker compose ps
docker compose logs --tail=100 builder
curl http://127.0.0.1:18765/api/health
```

Если порт занят, задайте другой `BUILDER_PORT`. После пересборки обновите
страницу без кеша.

## Подписка не загружается

Проверьте доступ Docker к интернету и DNS, срок действия ключа и необходимость
HWID Happ. Сообщение о локальном или служебном адресе означает, что защита
загрузчика заблокировала небезопасный URL.

## Узел пропущен

Рядом с узлом отображается причина. XHTTP/SplitHTTP не поддерживаются
sing-box 1.12.17 и не попадают в результат. Недоступный сервер может успешно
пройти синтаксическую сборку, но не пройдёт проверку `AUTO` в Yacd.

## Yacd не открывается

Проверьте, что sing-box запущен, IP роутера указан верно, firewall разрешает
доступ к порту `9090` из LAN, а пароль совпадает с `secret` итогового конфига.

## После запуска нет интернета

Немедленно остановите сервис:

```sh
/etc/init.d/sing-box stop
/etc/init.d/sing-box disable
```

Верните рабочий конфиг и проверьте его до следующего запуска:

```sh
sing-box check -c /etc/sing-box/config.json
```

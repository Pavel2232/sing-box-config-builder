# OpenWrt и маршрутизация

## Установка конфига

Скопируйте готовый файл в `/etc/sing-box/config.json` и выполните:

```sh
rm -f /etc/sing-box/cache.db
sing-box check -c /etc/sing-box/config.json
/etc/init.d/sing-box enable
/etc/init.d/sing-box restart
```

Пустой вывод проверки означает, что синтаксис принят. Удаление `cache.db`
сбрасывает сохранённый выбор Yacd, поэтому первым будет выбран `DIRECT`.

## Маршрутизация

- `SELECT` — основная группа для ручного выбора в Yacd;
- `DIRECT` — выбран по умолчанию;
- `AUTO` — периодически проверяет все добавленные узлы;
- встроенные и добавленные вручную DIRECT-домены обходят VPN;
- приватные сети исключены из TUN, чтобы сохранить доступ к роутеру и LAN.

По умолчанию Clash/Yacd API слушает `0.0.0.0:9090`. Открывайте его только из
домашней сети и не перенаправляйте этот порт из интернета.

## Аварийное отключение

Если после запуска пропала сеть:

```sh
/etc/init.d/sing-box stop
/etc/init.d/sing-box disable
```

Замените или исправьте конфиг, снова выполните `sing-box check` и только после
успешной проверки включайте сервис.

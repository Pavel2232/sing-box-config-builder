Sing-box Config Builder

Собирает полный config.json из VPN-подписок, оставляет DIRECT режимом по умолчанию, а мимо VPN отправляет только сервисы из встроенных белых списков.

Важно. Подписки содержат секретные ключи. Страница ничего не отправляет сторонним сервисам и не сохраняет ссылки. При запуске через sing-box-config-builder.py подписку скачивает локальный Python, поэтому CORS не мешает.

3. Настройки

Настройки подходят для sing-box версии 1.12.17.

Адрес 0.0.0.0:9090 открывает Yacd для устройств в домашней сети. Пароль берётся из рабочего конфига и сохраняется в браузере. Команда удаления cache.db ниже один раз сбросит старый выбор на DIRECT.
Сначала загрузите хотя бы одну подписку.

Команды после загрузки

Положите файл в /etc/sing-box/config.json, затем выполните: 

rm -f /etc/sing-box/cache.db

sing-box check -c /etc/sing-box/config.json

/etc/init.d/sing-box enable
/etc/init.d/sing-box restart

Пустой вывод команды sing-box check означает, что конфиг прошёл проверку.

Если после запуска пропал интернет

/etc/init.d/sing-box stop
/etc/init.d/sing-box disable

# Support

## Where to ask

- Builder bug: open a **Bug report** issue.
- Improvement or new behavior: open a **Feature request** issue.
- Setup or usage question: open a **Question** issue after reading the docs.
- Security vulnerability: follow [SECURITY.md](SECURITY.md), not a public issue.

Useful documentation:

- [Docker](docs/docker.md)
- [OpenWrt installation and recovery](docs/openwrt.md)
- [Troubleshooting](docs/troubleshooting.md)
- [Development](docs/development.md)

## Before opening an issue

Include the project commit/version, operating system, Python/Node versions,
launch method, exact sanitized error, and reproduction steps.

Never attach:

- a real subscription URL;
- a complete generated `config.json`;
- UUIDs, passwords, Reality keys, or a Happ HWID;
- screenshots that expose credentials.

Replace secrets with obvious fictional values while preserving the structure
needed to reproduce the problem.

VPN provider outages, expired subscriptions, blocked endpoints, and provider
account limits must be resolved with the provider. This project can only help
with parsing, generated configuration, routing, and its local server.

## По-русски

Для ошибки создайте **Bug report**, для идеи — **Feature request**, для вопроса
по установке — **Question**. Сначала проверьте документацию выше. Обязательно
замажьте ссылки подписок, UUID, пароли, Reality-ключи и HWID. Проблемы сервера
или аккаунта VPN решаются с провайдером.
